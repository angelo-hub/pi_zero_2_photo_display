ℹ️ About iCloud Authentication

  • ⚠️ First-Time Setup (SSH Required): Initial authentication must be done via SSH because it requires interactive 2FA: 
    ssh pi@photoframe.local
source ~/photoframe/venv/bin/activate
icloudpd --username YOUR_EMAIL --directory ~/photos --auth-only
    Enter your password and 2FA code when prompted.
  • After Initial Auth: Once authenticated via SSH, session cookies are saved for ~30 days. The web UI can then sync photos automatically.
  • Re-Authentication: When the session expires, you'll need to SSH in again to re-authenticate. You'll be notified when this is needed.
  • Privacy: Your password is never stored - only used to create session cookies.
