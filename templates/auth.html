ℹ️ About iCloud Authentication

  • App-Specific Password (Recommended): Generate one at appleid.apple.com → Sign-In and Security → App-Specific Passwords. This avoids 2FA prompts!
  • Two-Factor Auth: If using your regular password with 2FA enabled, you'll need to:
    1. Enter password and click Sign In
    2. Check your Apple device for the 6-digit code
    3. Enter password again + the code, click Verify
  • Session Duration: Sessions last ~30 days. You'll be notified when re-auth is needed.
  • Privacy: Your password is never stored - only used once to create a session.
